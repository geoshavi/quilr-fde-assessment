The four tasks

TASK 1

MCP Server

Stdio MCP server (official low-level SDK) exposing two tools with strict validation.

  • ASCII-only CUST-[0-9]{5} id format
  • No permissive type coercion (bool/NaN/Infinity rejected)
  • Genuine JSON-RPC -32602 errors, not swallowed exceptions
  • stdout reserved exclusively for protocol traffic
TASK 2

MCP Security Gateway

FastAPI HTTP/JSON-RPC reverse proxy with bearer-token role authorization.

  • admin_* tools blocked for non-admin roles (-32001)
  • Rejected calls never reach the downstream server
  • Caller's bearer token never forwarded downstream
  • Downstream errors sanitized before reaching the caller
TASK 3

Streaming PII Guardrail

Real-time redaction of emails, SSNs, and Luhn-valid cards in a streamed response.

  • Chunk-boundary safe (mid-token, mid-digit, multi-byte UTF-8)
  • Bounded pending state, not proportional to stream length
  • No whole-response buffering
  • Deterministic upstream/cancellation cleanup
TASK 4

Rate Limiter + Fallback Router

Per-tenant token admission plus a narrow primary/secondary routing policy.

  • 50,000 tokens / rolling 60s / tenant, on-disk SQLite
  • Concurrency-safe admission (no lost-update races)
  • Fallback only on primary 429 or 3000ms timeout
  • Generic provider errors never trigger fallback; errors sanitized

Reliability & security highlights

Zero secrets committed Downstream/provider errors sanitized No credential forwarding stdout/stderr isolation (Task 1) No lost-update races (Task 4) Offline, deterministic test suite
